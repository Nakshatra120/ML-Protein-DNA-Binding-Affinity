# Tutorial Notebooks

This directory contains a collection of step-by-step tutorial notebooks designed to make the protein–DNA binding affinity machine learning pipeline fully transparent and reproducible. These notebooks were added after forking the original repository by Carmen Masri, with the goal of offering a clear educational walkthrough for users who want to understand or extend the modeling workflow.

The tutorials cover three model families:

- Random Forest (regression and binary classification)
- Support Vector Machines (regression and binary classification)
- Neural Networks (regression and binary classification)

Each notebook executes the complete pipeline: loading data, preprocessing, creating cross-validation splits, training models, saving trained model objects, and exporting evaluation metrics. Intermediate files such as processed datasets, k-fold CV splits, trained model `.pkl` files, and metrics CSVs are automatically generated as the notebooks run.

## Purpose of the Tutorials

The tutorials are structured so that users can follow the entire model development process without needing to inspect the underlying scripts. They explain:

### 1. Dataset and Feature Structure  
The notebooks show how the dataset is organized, how protein and DNA sequence features are encoded, and how the binding affinity target is interpreted.

### 2. Data Preprocessing  
This includes handling missing values, scaling, normalization, and generating train/validation/test sets. The notebooks create k-fold cross-validation splits and save them for consistent reuse.

### 3. Model Training  
Each notebook trains a model specific to its category. The workflow includes defining hyperparameters, fitting across folds, saving the resulting models in the `models/` directory, and recording results.

### 4. Evaluation  
Regression models report metrics such as RMSE, MAE, and R². Classification models report accuracy, F1 score, precision, recall, and ROC-AUC. Evaluation results are saved in the `results/` directory. Plots and tables may also be generated to help users interpret performance.

### 5. Reproducibility  
Running any notebook will produce a well-organized set of intermediate files that document each stage of the pipeline. This enables comparisons across models and facilitates extension.

## Example: Random Forest Regression Tutorial

The `RF_regression_tutorial.ipynb` notebook demonstrates the full process:

1. Loading and inspecting the raw dataset from the `data/` directory  
2. Preprocessing (scaling, cleaning, formatting)  
3. Generating k-fold cross-validation splits  
4. Defining reasonable Random Forest hyperparameters  
5. Training a model for each fold and saving trained `.pkl` files  
6. Exporting performance metrics to CSV format  
7. Inspecting feature importances and analyzing errors

Other tutorials—SVM and neural networks, for both regression and binary classification—use the same structure so that users can compare model classes directly.

## How to Use These Notebooks

1. Clone or fork the repository.  
2. Install dependencies using the provided `requirements.txt` or conda environment file.  
3. Launch Jupyter Notebook or Jupyter Lab.  
4. Open any notebook inside the `tutorial notebooks/` directory.  
5. Run all cells sequentially. All intermediate and output files will be generated automatically.

No manual script execution is required; the notebooks are self-contained.

## Extending the Models

Because the notebooks are modular, users can:

- Add new sequence encodings  
- Experiment with additional feature sets  
- Implement new models such as gradient boosting or deep learning architectures  
- Add hyperparameter tuning frameworks  
- Combine models into ensembles

The structure is designed to encourage experimentation while maintaining reproducibility.
